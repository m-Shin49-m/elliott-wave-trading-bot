# 📋 Что нужно перед запуском скрипта

## ✅ Проверено автоматически:
- ✅ Git установлен (версия 2.43.0)
- ✅ Скрипт setup_github.sh готов
- ✅ .gitignore настроен
- ✅ config.example.py создан

## 📝 Что нужно подготовить ВАМ:

### 1. Аккаунт на GitHub
- Если нет аккаунта: https://github.com/signup
- Запомните логин и пароль

### 2. Создать репозиторий на GitHub
**ВАЖНО:** Создайте репозиторий ПЕРЕД запуском скрипта!

Шаги:
1. Зайдите на https://github.com/new
2. **Repository name**: `elliott-wave-trading-bot` (или любое другое имя)
3. **Description**: `Elliott Wave Trading Bot for Crypto` (опционально)
4. **Visibility**: 
   - 🔒 **Private** (рекомендуется - только вы видите код)
   - 🌐 Public (все видят код)
5. ❌ **НЕ ставьте галочки** на:
   - ❌ Add a README file
   - ❌ Add .gitignore
   - ❌ Choose a license
6. Нажмите **"Create repository"**

### 3. Скопировать URL репозитория
После создания репозитория GitHub покажет URL, например:
```
https://github.com/YOUR_USERNAME/elliott-wave-trading-bot.git
```
Скопируйте этот URL - он понадобится в скрипте!

### 4. Подготовить данные для Git
Скрипт спросит:
- **Ваше имя** (для Git коммитов)
- **Email** (для Git коммитов)

Можно использовать:
- Реальное имя или никнейм
- Email (может быть любой, даже несуществующий)

---

## 🚀 Готовы? Запускайте скрипт!

```bash
cd /opt/elliott_wave_bot
./setup_github.sh
```

Скрипт будет задавать вопросы по ходу работы - просто отвечайте на них!
