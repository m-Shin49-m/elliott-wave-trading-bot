## 📋 Команды управления

### Просмотр статуса
```bash
sudo systemctl status elliott-bot.service
```

### Просмотр логов в реальном времени
```bash
journalctl -u elliott-bot.service -f
```

### Последние 50 строк логов
```bash
journalctl -u elliott-bot.service -n 50
```

### Логи за сегодня
```bash
journalctl -u elliott-bot.service --since today
```

### Перезапуск сервиса
```bash
sudo systemctl restart elliott-bot.service
```

### Остановка сервиса
```bash
sudo systemctl stop elliott-bot.service
```

### Запуск сервиса
```bash
sudo systemctl start elliott-bot.service
```

### Отключить автозапуск (если нужно)
```bash
sudo systemctl disable elliott-bot.service
```

### Включить автозапуск обратно
```bash
sudo systemctl enable elliott-bot.service
```

## ⚠️ Примечания

1. **После изменения config.py** перезапустите сервис:
   ```bash
   sudo systemctl restart elliott-bot.service
   ```

2. **При перезагрузке системы** бот запустится автоматически

3. **Если бот упадет**, он автоматически перезапустится через 5 секунд

4. **Для просмотра логов** используйте `journalctl`, а не файл `elliott_bot.log` (он может быть неактуален при работе через systemd)
