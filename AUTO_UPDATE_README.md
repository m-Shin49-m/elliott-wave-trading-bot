# 🔄 Автоматическое обновление вероятностной модели

Бот теперь **автоматически обновляет** вероятностную модель! Вам больше не нужно делать это вручную.

## 🎯 Как это работает

### 1. **Встроенное обновление в боте** (основной способ)
- Бот **автоматически проверяет** необходимость обновления модели каждый час
- Обновляет модель если:
  - Прошло 24+ часов с последнего обновления
  - Накопилось 10+ новых сигналов
- Обновление происходит **в фоне**, не мешая работе бота

### 2. **Systemd Timer** (дополнительный способ)
- Запускает обновление модели **раз в день в 03:00**
- Работает независимо от бота
- Можно настроить через `setup_auto_update.sh`

## ⚙️ Настройки

В `config.py` добавлены новые параметры:

```python
# Автоматическое обновление модели
PROB_MODEL_AUTO_UPDATE = True  # Включить автообновление
PROB_MODEL_AUTO_UPDATE_HOURS = 24  # Обновлять раз в N часов
PROB_MODEL_MIN_NEW_SIGNALS = 10  # Минимум новых сигналов для обновления
```

### Настройка интервала обновления:
- `PROB_MODEL_AUTO_UPDATE_HOURS = 12` - обновлять раз в 12 часов
- `PROB_MODEL_AUTO_UPDATE_HOURS = 48` - обновлять раз в 2 дня
- `PROB_MODEL_AUTO_UPDATE = False` - отключить автообновление

## 🚀 Установка systemd timer (опционально)

Если хотите дополнительное обновление через systemd:

```bash
cd "/home/shin/Рабочий стол/elliott_wave_bot"
sudo bash setup_auto_update.sh
```

Это создаст таймер, который будет обновлять модель раз в день в 03:00.

## 📊 Проверка работы

### Проверить, когда последний раз обновлялась модель:
```bash
ls -lh prob_model.json
```

### Проверить логи автообновления в боте:
```bash
journalctl -u elliott-bot.service -f | grep -i "обновл\|update"
```

### Проверить статус systemd timer (если установлен):
```bash
sudo systemctl status update-model.timer
sudo systemctl list-timers update-model.*
```

## 🔍 Ручное обновление (если нужно)

## 💡 Рекомендации

1. **Оставьте автообновление включенным** - это улучшит точность вероятностей
2. **Проверяйте логи** раз в неделю, чтобы убедиться, что обновления проходят успешно
3. **При 100+ сигналах** модель станет значительно точнее
