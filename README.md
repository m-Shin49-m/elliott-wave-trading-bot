# Elliott Wave Trading Bot

Профессиональный торговый бот для криптовалют, использующий анализ волн Эллиотта, multi-timeframe анализ, детекцию ликвидности и вероятностную модель на основе бэктеста.

## 🎯 Основные возможности

- **Анализ волн Эллиотта**: Автоматическое определение 5-волновых паттернов (импульсных и коррекционных)
- **Multi-Timeframe анализ**: Согласованность сигналов на разных таймфреймах (15m, 1h)
- **Детекция ликвидности**: Поиск уровней ликвидности и sweep-сетапов
- **Вероятностная модель**: Статистическая оценка вероятности достижения TP/SL на основе исторических данных
- **Управление рисками**: ATR-based расчет целей и стоп-лоссов
- **Фильтры качества рынка**: Проверка объема, спреда, волатильности
- **Интеграция новостей**: Анализ новостного фона через RSS
- **Telegram уведомления**: Отправка сигналов и статусов в Telegram

## 📋 Требования

```bash

```


### Запуск через systemd (Linux)

1. Скопируйте service файл:
```bash
sudo cp elliott-bot.service /etc/systemd/system/
sudo chmod 644 /etc/systemd/system/elliott-bot.service
```

2. Отредактируйте `/etc/systemd/system/elliott-bot.service` и добавьте переменные окружения:
```ini
Environment="TELEGRAM_TOKEN=your_token"
Environment="TELEGRAM_CHAT_ID=your_chat_id"
```

3. Запустите сервис:
```bash
sudo systemctl daemon-reload
sudo systemctl enable elliott-bot.service
sudo systemctl start elliott-bot.service
```

4. Проверка статуса:
```bash
sudo systemctl status elliott-bot.service
journalctl -u elliott-bot.service -f
```

## 🔧 Основные компоненты

### 1. ElliottWaveAnalyzer (`elliott_wave.py`)

Анализирует ценовые данные и ищет паттерны волн Эллиотта:

- **Поиск пивотов**: Определение локальных максимумов и минимумов
- **Волновая структура**: Идентификация 5-волновых паттернов (1-2-3-4-5)
- **Оценка качества**: Система оценки от 0 до 100 на основе правил Эллиотта
- **Фильтры рынка**: Проверка объема, спреда, волатильности
- **ATR-цели**: Расчет TP/SL на основе Average True Range

**Ключевые методы:**
- `get_historical_data()` - получение данных с биржи
- `find_pivots()` - поиск точек разворота
- `get_signal()` - основной метод получения сигнала
- `_check_wave()` - проверка волновой структуры

### 2. LiquidityZones (`liquidity_zones.py`)

Определяет уровни ликвидности и детектирует sweep-сетапы:

- **Поиск равных high/low**: Кластеризация уровней с одинаковыми ценами
- **Sweep detection**: Определение снятия ликвидности
- **Volume spike**: Обнаружение всплесков объема
- **Retracement**: Проверка возврата после прокола

### 3. ProbModel (`prob_model.py`)

Вероятностная модель на основе исторических данных:

- **Бэктест статистика**: Вероятности достижения TP1/TP2/TP3/SL
- **Бакетирование**: Группировка по качеству, тренду, направлению
- **Эмпирические вероятности**: Не предсказывает будущее, показывает статистику похожих сетапов

### 4. News Integration (`news.py`)

Анализ новостного фона:

- **RSS парсинг**: Получение новостей из Coindesk, Cointelegraph
- **Ключевые слова**: Фильтрация по релевантным терминам
- **Сентимент анализ**: Определение позитивного/негативного тона

## ⚙️ Конфигурация

```python
USE_ATR_TARGETS = True
ATR_SL_MULT = 1.6
ATR_TP1_MULT = 1.0
ATR_TP2_MULT = 2.0
ATR_TP3_MULT = 3.0

# Ликвидность
LIQUIDITY_FILTER_ENABLED = True
LZ_LOOKBACK_BARS = 200
LZ_SWEEP_RETRACE_PCT = 0.15
```

## 📈 Как работает бот

1. **Получение данных**: Загружает исторические свечи с Binance через CCXT
2. **Анализ таймфреймов**: Анализирует каждый таймфрейм отдельно
3. **Поиск паттернов**: Ищет волны Эллиотта и уровни ликвидности
4. **Фильтрация**: Применяет фильтры качества рынка
5. **Агрегация**: Объединяет сигналы с разных таймфреймов
6. **Оценка вероятности**: Применяет вероятностную модель
7. **Отправка сигнала**: Если качество выше порога - отправляет в Telegram

## 🐛 Решение проблем

### Бот не запускается
- Проверьте Python версию: `python3 --version` (должна быть 3.8+)
- Проверьте зависимости: `pip list | grep telegram`
- Проверьте логи: `tail -f elliott_bot.log`

### Нет сигналов
- Проверьте фильтры качества в `config.py` - возможно пороги слишком высокие
- Проверьте логи на причины отклонения: `grep "reject" elliott_bot.log`
- Убедитесь, что рынок активен (достаточный объем)

### Ошибки Telegram
- Проверьте токен и chat_id
- Убедитесь, что бот добавлен в чат
- Проверьте интернет-соединение

### Ошибки Binance API
- Проверьте лимиты API (rate limiting)
- Убедитесь, что пара торгуется на Binance
- Проверьте интернет-соединение
