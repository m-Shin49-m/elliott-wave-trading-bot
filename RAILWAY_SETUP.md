## 📋 Пошаговая инструкция

### Шаг 1: Подготовка репозитория

✅ Уже готово:
- `Procfile` - команда запуска
- `railway.json` - конфигурация Railway
- `requirements.txt` - зависимости
- `config.example.py` - шаблон конфигурации

### Шаг 2: Загрузить код на GitHub

Если еще не загружено:
```bash
cd ~/elliott-wave-trading-bot
git add Procfile railway.json
git commit -m "Add Railway configuration"
git push origin main
```

### Шаг 3: Создать проект на Railway

1. Зайдите на https://railway.com/dashboard
2. Нажмите **"New Project"**
3. Выберите **"Deploy from GitHub repo"**
4. Выберите репозиторий: `m-Shin49-m/elliott-wave-trading-bot`
5. Railway автоматически определит Python проект

### Шаг 4: Настроить переменные окружения

В настройках проекта Railway добавьте переменные:

**Обязательные:**
- `TELEGRAM_TOKEN` = `7527369349:AAHUsDd7y--kBUDhw4AIDqEFuSUa4NzBHLQ`
- `TELEGRAM_CHAT_ID` = `1170691157`

**Как добавить:**
1. В проекте Railway откройте вкладку **"Variables"**
2. Нажмите **"New Variable"**
3. Добавьте каждую переменную:
   - Name: `TELEGRAM_TOKEN`
   - Value: ваш токен
4. Повторите для `TELEGRAM_CHAT_ID`

### Шаг 5: Настроить тип сервиса

1. В настройках сервиса найдите **"Settings"**
2. Убедитесь что выбран тип: **"Worker"** (не Web Service)
3. Railway автоматически использует `Procfile` с командой `worker: python3 bot.py`

### Шаг 6: Деплой

Railway автоматически:
1. Клонирует код с GitHub
2. Установит зависимости из `requirements.txt`
3. Запустит бота командой из `Procfile`

## ⚙️ Конфигурация

### Procfile
```
worker: python3 bot.py
```
Указывает Railway запускать бота как worker процесс.

### railway.json
```json
{
  "deploy": {
    "startCommand": "python3 bot.py",
    "restartPolicyType": "ON_FAILURE",
    "restartPolicyMaxRetries": 10
  }
}
```

## 🐛 Решение проблем

### Бот не запускается:
1. Проверьте логи в Railway
2. Убедитесь что переменные окружения установлены
3. Проверьте что `Procfile` существует и правильный

### Ошибка "Module not found":
1. Проверьте `requirements.txt`
2. Railway должен установить зависимости автоматически
3. Если проблема, добавьте недостающие пакеты в `requirements.txt`

### Бот не отправляет сигналы:
1. Проверьте `TELEGRAM_TOKEN` и `TELEGRAM_CHAT_ID`
2. Проверьте логи в Railway
3. Убедитесь что бот запущен (статус "Running")

### Файловая блокировка:
Бот использует файловую блокировку для предотвращения дубликатов. На Railway это не проблема, т.к. запускается только один экземпляр.
