# Отслеживание TP/SL

## Описание

Реализована автоматическая система отслеживания исполнения уровней Take Profit (TP) и Stop Loss (SL) для всех открытых сигналов.

## Функциональность

### Новые поля в CSV

В файл `signals_history.csv` добавлены следующие поля:

- `tp1_hit` - достигнут ли TP1 (0/1)
- `tp2_hit` - достигнут ли TP2 (0/1)
- `tp3_hit` - достигнут ли TP3 (0/1)
- `sl_hit` - сработал ли Stop Loss (0/1)
- `close_price` - цена закрытия позиции (если закрыта)
- `close_time` - время закрытия позиции (если закрыта)

### Статусы сигналов

- `opened` - сигнал открыт, позиция активна
- `closed_sl` - позиция закрыта по Stop Loss
- `closed_tp3` - позиция закрыта по TP3 (все цели достигнуты)
- `cancelled` - сигнал отменен (существующий функционал)

### Логика проверки

**Для BUY сигналов:**
- TP1/TP2/TP3 считаются достигнутыми, если цена >= соответствующего уровня
- SL срабатывает, если цена <= уровня SL
- После достижения TP1 можно достичь TP2, после TP2 - TP3

**Для SELL сигналов:**
- TP1/TP2/TP3 считаются достигнутыми, если цена <= соответствующего уровня
- SL срабатывает, если цена >= уровня SL
- После достижения TP1 можно достичь TP2, после TP2 - TP3

### Уведомления в Telegram

При срабатывании уровней отправляются уведомления:
- ✅ TP1 достигнут!
- ✅ TP2 достигнут!
- 🎯 TP3 достигнут!
- ❌ Stop Loss сработал!
- 🔒 Позиция закрыта

## Как это работает

1. **Проверка выполняется автоматически** в каждом цикле основного цикла бота
2. **Получение текущей цены** через API биржи Binance
3. **Сравнение с уровнями** всех открытых сигналов
4. **Обновление CSV файла** при обнаружении изменений
5. **Отправка уведомлений** в Telegram при срабатывании уровней

## Резервное копирование

При каждом обновлении CSV создается резервная копия: `signals_history.csv.backup`

## Миграция существующих данных

Все существующие сигналы автоматически получили новые поля со значениями по умолчанию:
- `tp1_hit`, `tp2_hit`, `tp3_hit`, `sl_hit` = "0"
- `close_price`, `close_time` = ""

## Производительность

- Проверка выполняется только для сигналов со статусом "opened"
- Минимальная нагрузка на API (один запрос цены на цикл)
- Оптимизированное чтение/запись CSV файла
